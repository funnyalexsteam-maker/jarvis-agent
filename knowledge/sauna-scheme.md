# Схема установки печи: заполнение пропусков «не менее ___ мм»

Задача Александра: заполнить пропуски на схеме установки банной печи (кирпичная печь с трубой + металлическая печь у стены). Значения нанесены прямо на картинку скриптом `sauna-scheme/fill.py` (PIL, координаты подобраны под оригинал 1512x2016).

Файлы: `sauna-scheme/original.jpg` (исходник), `sauna-scheme/filled_v3.jpg` (результат), `sauna-scheme/fill.py`.
Запуск: `python3 -I fill.py original.jpg out.jpg`. Цвет: синий = подтверждено, красный = нет.

## Значения (СП 7.13130.2013, ред. 27.03.2025)

| Место на схеме | Значение | Источник |
|---|---|---|
| Угол при трубе дальше 3 м от конька | 10° | п. 5.10 |
| Возвышение над коньком (до 3 м) | 500 мм | п. 5.10 |
| Толщина стенки дымохода | 120 мм | п. 5.11 |
| Отступка трубы от кровли | 130 мм | сторонний сайт, в тексте СП не найдено |
| Разделка от внутренней поверхности дымохода | 500 мм (не защищённых), 380 мм (защищённых) | Приложение Б.1 |
| Выше и ниже перекрытия | 70 мм | п. 5.14 |
| Отступка у печи до горючей стены | 260 мм (стенка 120, открытая, стена не защищена) | таблица Б.1 |
| Предтопочный лист | 700 x 500 мм, длинной стороной вдоль печи | п. 5.21 |

Таблица Б.1 (стенка печи / отступка / стена не защищена / защищена): 120 открытая 260/200; 120 закрытая 320/260; 65 открытая 320/260; 65 закрытая 500/380.

## Не подтверждено (красные на схеме)

- 140 мм у пола: п. 5.22 даёт 140 до дна зольника и 210 до дна дымохода (пол из горючих). Какое из двух показывает стрелка, неясно.
- 500 мм слева у карниза: что показывают стрелки, не определено, это догадка.
- 1,0 м до стены у металлической печи (0,5 м с экраном): прямой нормы в СП не найдено, типично для паспортов. Лист перед топкой на верхнем рисунке: 0,5 x 0,7 м.

## Как закрыть

Нужен паспорт конкретной печи (модель) или страница с таблицей отступов. Паспорт производителя приоритетнее СП.

## Заметки по инструментам

- Прямой доступ к consultant.ru, garant.ru, cntd.ru и др. в облачной сессии блокирует прокси окружения (403). Сеть окружения меняется только до старта сессии.
- Коннектор Parallel Search (web_search, web_fetch) работает, но у бесплатного тарифа без ключа есть лимит запросов. Ключ: platform.parallel.ai.
- Приложение Claude на iPhone показывает HTML-теги как текст, отвечать там нужно без HTML.
