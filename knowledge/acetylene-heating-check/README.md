# Таблица 1: проверка системы отопления генераторного цеха ацетиленовой станции

Задание: здание I степени огнестойкости, категория А (Д), помещения: газодувки, генераторное отделение, раскупорочная, промежуточный склад карбида кальция, насосная, газовая котельная. Принято: водяное отопление 150 °C, гладкие приборы, котельная отделена от насосной деревянной перегородкой, выход из котельной в соседнее помещение, допускается рециркуляция. Нужно заполнить таблицу 1 (вопрос / принято / требуется / ссылка / вывод).

Файлы: `tablica-1-generatornyj-ceh.docx` (итоговая таблица, A4 альбомная), `build_table.py` (сборка).

## Итог

Нормы, разрешённые для задания: У-867-00-4 (Указания по проектированию производства ацетилена для газопламенной обработки металлов, раздел 8 «Отопление и вентиляция»), СП 60.13330.2020, СП 4.13130.2013, ФЗ-123. Решение Александра: СП 60 использовать можно.

## Как проверено

- У-867-00-4 прочитан по фотографиям страниц 22-25 (п. 7.11-9.07). Раздела про строительные решения (п. 2.xx, на который ссылается п. 8.17) у меня нет.
- СП 60.13330.2020 (с Изм. 3) и первоначальная редакция 2020 сверены по п. 6.1.14, 6.2.9, 6.4.1-6.4.2, 7.3.13, табл. Б.1: совпадают.
- СП 4.13130.2013 п. 6.9, ФЗ-123 ст. 88-89 и табл. 23 прочитаны в тексте.
- В СП 7.13130.2013 (обе редакции) и в ФЗ-123 требований по температуре воды, приборам и рециркуляции нет.

## Допущения

- У-867 и СП 60 различаются по температуре воды: 130 и 115 °C. Принято более строгое значение. Вывод по строке не меняется при любом из двух.
- «Расходный склад» из У-867 соответствует «промежуточному складу карбида кальция» из задания.
- В генераторном отделении по У-867 водяные гладкие приборы допустимы, а по СП 60 п. 6.2.9 водяное отопление там не допускается (карбид и вода). Это моя привязка к п. 6.2.9, она влияет на строку 1.
- Все помещения считаются категории А, кроме котельной. Если «Д» относится к конкретным помещениям, строки 1, 5 для них могут быть мягче.
- Газовая котельная по СП 89.13330.2016 прил. Б обычно категории Г, в задании «Д».
