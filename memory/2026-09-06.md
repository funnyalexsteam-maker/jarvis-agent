- После первого подключения десктопный VS Code один раз словил обрыв туннеля (WebSocket close 1006 → потом "VS Code gateway is not currently running") — помог `systemctl --user restart code-tunnel.service` на сервере (свежая relay-сессия), после этого десктоп подключился успешно
